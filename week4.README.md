# README
Canva Docs — Individual project proposal
This repository holds the proposal and document plan for an individual documentation project. This phase delivers the proposal only. The user-facing guides listed in the plan below are scheduled for later sessions and are not written yet.

1. Product and target reader
Product: Canva. Canva is a free online graphic design platform that lets people create social media posts, presentations, posters, and other visual content using drag-and-drop templates. No professional design training is required.
Target reader: small business owners and social media managers. They need professional-looking visuals on a tight schedule, but have no formal design background. They prefer ready-to-use templates over complex design software, and they usually work alone rather than in a design team.

2. Platform
The product runs in a web browser and on iOS / Android apps. This documentation set is written in Markdown and hosted on GitHub, so every change has a reviewable history.

3. Related tasks and the first core task
The three tasks below are related because they form one continuous workflow: a reader starts a design, adapts it, and then delivers it.
- Task 1 — Create a social media post from a template. Choose a template, set the size, and replace the sample content.
- Task 2 — Customize the design. Edit text, colors, fonts, and images.
- Task 3 — Download or share the finished design. Export the file or send a link to a colleague.
First core task: Task 1 — Create a social media post from a template.
This is the first core task because it is the entry point every reader needs: without a starting design, the other two tasks cannot happen. It is also the step where new readers most often get stuck, so it will be covered first by quick-start.md.

4. Scope
In scope for this phase
- The proposal, the reader definition, the task list, and the first core task
- A feasible document plan that states which files will exist and when
- A preserved copy of the earlier GitHub practice tutorial
Out of scope for this phase
- The actual guides (quick-start.md, user-guide.md, faq.md) — these are written in later sessions
- Advanced Canva features such as brand kits, team collaboration, and animation
- Screenshots and other image assets
  
5. Practice material
   
The earlier tutorial, "Creating a private GitHub repository", is saved under practice/create-private-repo.md. It is kept as practice material and is separate from this proposal. It was copied before README.md was rewritten, so the original wording is not lost.

6. Tool choice
   
I chose the GitHub web editor (the pencil icon on the file view) to write these documents because it needs no local setup and shows a live Markdown preview. It also records every change as a clear commit, which helps a reviewer see which file changed and why. Markdown keeps the files plain-text, so they can be reused and compared across later sessions.
