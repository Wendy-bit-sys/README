# README
temporary test repository
Prerequisites
 
1. A desktop computer with a web browser

2. An active GitHub account, already signed in

3. GitHub website set to English interface
 
Steps
 
1. On the GitHub homepage, click the plus “+” icon at the top right corner and select New repository.

2. Enter a repository name in the required input box. You may add an optional description.

3. Select the Private option for repository visibility.

4. Tick the checkbox of Add a README file. Leave other options as default.

5. Click the green Create repository button to finish creation.
 
Result Check
 
✅ Success sign: You are directed to the new repository page. The page shows the “Private” label and the content of the README file is visible.
❌ If failed: Check whether you selected Public by mistake or forgot to check the README option.
